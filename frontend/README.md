# Frontend — RM Peluquería · Barbería

SPA en React + Vite del gestor de citas.

```bash
npm install
cp .env.example .env   # VITE_API_URL=/api (proxy de Vite → http://localhost:8000)
npm run dev            # http://127.0.0.1:5173
npm run build          # genera dist/
npm run lint
```

Documentación completa del proyecto (stack, puesta en marcha, variables de entorno, despliegue): ver el [README principal](../README.md).
